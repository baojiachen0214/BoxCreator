# 内部几何清单

此文件由 AI 提取、检查并维护，不作为用户的额外输入门槛。PDF 中任意路径的工程含义无法可靠地仅凭颜色自动推断，当前工具不提供“任意 PDF 自动转折叠盒”的命令。

## 坐标和字段

长度单位统一为 mm，原点是画布左下，x 向右、y 向上，与规整后的 PDF 坐标对应；Blender 使用米，转换比例为 0.001。不要拿屏幕像素坐标直接填入。

```json
{
  "canvas_mm": [100, 100],
  "panels": [
    {"id": "base", "outline": [[10,10],[50,10],[50,50],[10,50]]},
    {"id": "side", "outline": [[50,10],[90,10],[90,50],[50,50]],
     "holes": [[[60,20],[70,20],[70,30],[60,30]]],
     "parent": "base", "hinge": [[50,10],[50,50]],
     "angle_deg": -90, "stage": [0.15,0.6]}
  ]
}
```

`outline` 是一个不自交的面板外环，端点无需重复。`holes` 是真正切走的闭合内环，必须严格在本面内部。缺口属于外环而不是相切的内孔。相邻面共边不重叠；外部轮廓和孔都保留物理纸张意义。画布不是成品外包尺寸。

每个净片只有一个没有 `parent` 的根面。每个其他面通过一个直线 `hinge` 连到父面。两个有序端点定义折叠轴方向；`angle_deg` 按右手定则绕轴旋转，必须在 ±180° 内。父级的运动自动传递到子级。不能因为屏幕上“应该朝里”就猜正负号，先做低帧无贴图检查。

`stage` 是整个视频的归一化时间 `[开始,结束]`，当前实现限制在 0..0.8，推荐于 0.75 前折完。末尾 25% 视频做完整环绕；不要把仍在折叠的动作误当闭合成品验收。默认 stage 为 `[0.1,0.6]`。时间安排可以改，几何和目标折角不能顺手变化。

## 工具检查与摘要

`validate` 检查坐标有限、有效多边形、孔在面内、面在画布内、平面面积不重叠、唯一根、父面存在、无环、铰链沿父子共同纸张边界、整个净片为一个实体。边界比对允许 0.01 mm 浮点容差，这不是制造公差。孔的三角化面积必须与有效纸张面积一致。

`geometry_sha256` 包含画布、面编号、外环/孔、父面、铰链与目标折角，忽略面板列表顺序、时间、备注与贴图路径。语义相同但点序不同仍可能改变摘要；它用来追踪版本，不作为几何同构证明。画面另用文件 SHA-256 跟踪，两者均应记录在交付清单。

`scene` 为各面生成带孔三角形。渲染器在每个面自己的铰链原点下放置网格，使用同一原始纸张坐标建立 UV。子级铰链在父级局部坐标中；不应把世界坐标折完后再次应用父变换。

## 适用范围与扩展

- 一份清单是一片连通纸张。一套多款可共享几何，但不同净片分别建清单，不能让重叠的不同款通过检查。
- 支持多边形轮廓和内部孔、树状刚性直线铰链。不支持同一面多个独立父铰链、弯曲折痕、闭链机构、自动接触约束和软体纸张。
- 曲线在动画中需按明确精度离散。生产 PDF 保留原曲线，不依赖三角网格反向输出刀线。
- 纸厚、粘接、卡舌接触、倒角和内面材质需按结构扩展。示例不使用 Solidify，以免没有设计公差的厚度把扣合问题掩盖。
- 多边形自洽不等于匹配 PDF；务必将路径叠回源刀板，检查每个洞、折线端点、外轮廓和已知边长。最细纸桥、耳片根部、窗口到折痕的最短距离要单独量测。

工具异常时先检查清单，不通过放宽容差、删除孔或改纸张尺寸来消除报错。需要一种当前模型表达不了的结构时，保留原始工程意图并扩展建模方法。
