# 从刀板到成品：AI 如何做判断

按依赖关系推进，不必机械地逐项执行。已经确认的内容直接复用；发现结构问题时回到结构，发现画面问题时留在设计层。用户最新的明确修订优先，不能让旧版本的口头偏好覆盖它。

## 接收输入，先建立共同事实

最低输入是刀板 PDF 和一句风格说明。参考图、品牌文案、材质、印厂要求可选。先检查文件，不把能自己读出的信息再问用户。

1. 渲染 PDF 看全页和局部，同时读取页面尺寸、页面原点、旋转、UserUnit、路径、字体、图片、图层和专色。视觉阅读与数值读取互相校验；扫描图需确认标尺或已知尺寸。
2. 区分“生产用连体刀板”“若干独立面稿”“效果图”。独立面稿不能直接宣称是一片可裁可折的盒子。若需要补成连体结构，先画结构草案并验证相邻面、糊口、开孔和底部，不静默臆造扣合方式。
3. 给每款、每页、每面稳定编号，例如 `variant-a/front`。记录实际宽高和方向，标注刀线、压痕、虚线、穿孔、开窗、糊口、插舌、提手、底锁。颜色只是线索，不自动等于刀/折含义。
4. 保留原 PDF 不改写。工作用页面若有旋转、非零原点或特殊 UserUnit，规整时同步转换所有坐标和 PageBox；用已知边长和渲染叠图确认没有缩放、翻转或位移。

需要问的是影响成品的具体歧义：哪条线切开、窗口是否真的挖空、参考图和图纸尺寸冲突时听谁的、能否改变结构。输出格式通常直接沿用完整交付标准。不用一串问卷拖住可以开始的工作。

## 确认能力，再投入制作

验证当前环境的 PDF 阅读/编辑、AI 画图、矢量导出、Blender 和视频编码能力。外部服务先验证一个小样的真实导出权限、矢量内容和尺寸；成功后继续整批，不把小样成功当成全部完成。

生成式图像工具适合插画；几何工具适合尺寸、轮廓、裁切和出血。矢量原生图案可直接设计；需要 AI 插画时使用可用的图像生成工具。不要拿几根简化线条冒充用户要求的完整插画。无需为了本任务下载大型本地模型；工具不足时说明具体缺口并选择已具备的替代路线。

云端描摹可使用 Vectorizer.AI 或同类服务，也可本地描摹，选择依据是用户偏好、效果、授权和可导出性。上传未发布画稿前确认已有对应素材和服务的上传授权；某一次授权不延伸到所有未来客户文件。不要在仓库写入账号、Cookie、密钥或操作截图。优先使用现有连接或安全凭据存储，不让用户把密钥写进聊天。

## 结构先稳定，画面再准确落位

画一张有编号和方向箭头的净结构图，并记录面之间的连接关系。共用边是折线时，不应各画一条切线把整张纸切散。糊口属于纸张实体，不能仅在效果图中暗示。窗口孔和外轮廓都必须对应真实路径。

AI 创建 [几何清单](geometry.md)，用 `boxcreator validate` 验证一个连通的纸片、无重叠平面、共享铰链和有效孔洞，再逐条对照源刀板。自动验证只检查清单内部是否自洽，不能证明提取得对。

如果已知结构正确而画面出错，冻结刀线、窗口和扣合尺寸。窗口边“变宽/变窄”可能指视觉白边，也可能指纸张余量，先用标注对比图澄清含义；不要把整个面按比例缩放来近似恒定宽度的内缩。

开孔轮廓若是曲线，原始 Bézier 曲线保留在矢量母版。动画网格可以按明确弦差离散，例如在任务中选择 0.05 mm 并记录误差，不能反过来用低精度网格替换生产刀线。

## 先做好一个面，再完成整个系列

按每个面的实际长宽比生成画稿。先做完整矩形画面并留出裁切余量，最后由精确窗口/轮廓裁切；不要让图像模型负责毫米级刀线或文字排版。需要文字时单独排版、校对，并使用允许嵌入或转曲的字体。

可用的画稿提示结构：

> 为纸盒的 {面编号} 创作 {风格} 插画。画幅比例 {宽}:{高}，布局方向 {方向}。主要角色和装饰避开 {窗口/折线/安全区}，与相邻 {面编号} 保持 {配色/连续图案}。这里只生成印刷画面；精确裁切由后续几何处理。需要出血的位置让背景自然延伸。文案由后期矢量排版处理。

参考图用来分析配色、笔触、角色比例、装饰密度和窗口周围的构图；避免只抓“公主”“机械”等关键词便套一个无关模板。风格需要与内容、品牌和用户授权相符。角色、屋顶、边框、底部和接缝要成体系。

先检查一个代表面的构图与矢量化质量，再完成正反、左右、顶、底、插舌及应印刷的糊口等全部面。各面分别完成后，放回完整展开图再次检查。需要多款时用稳定 ID 和同一结构母版，明确哪些差异是配色、图稿或结构。

“整面重画”意味着重新安排角色、边框和装饰，不能仅遮掉旧边框、加粗描边或挪动刀线。局部修改意味着只改批准的局部，不顺手重做其他面的内容。

## 真矢量、颜色和分层

对已认可画稿做矢量化，获得 SVG/PDF 路径，再看小尺寸细节、颜色块、锯齿、透明度和节点数量。扩大位图分辨率、将 PNG 嵌入 SVG、用剪裁蒙版包住图片，都不算纯矢量。

描摹不一定保留正确文字、专色和颜色。文字用经过校对的字形重建；生产 PDF 按印厂的目标 ICC、专色命名、总墨量和叠印规则准备。通用 CMYK 转换不能代替明确印刷条件，添加 OutputIntent 也不能自行宣称 PDF/X 合格。

建立两份纯矢量源 PDF：画面和工艺线。工艺线中的切、折、孔等可有不同专色/线型，但在交付 PDF 中统一归入一个 `02_Dieline` 图层，全部画面归入 `01_Artwork`。图层从制作初期分开，避免最后按颜色猜分离。工具合成时逐页严格比对 Media/Crop/Trim/BleedBox，不为适配图稿缩放刀板。

出血沿实体外轮廓向外扩展；开窗周边按印厂要求处理画面延伸和安全距离，分别记录，不能混称“出血”。3 mm 是常见示例值，实际以本任务和印厂要求为准。生成画面的白底不能遮住刀线，刀线不应烘焙到印刷贴图里。

`boxcreator assemble` 保留源内容与图层，不替你创建 ICC、糊口、出血或矢量描摹。`boxcreator svg` 每款导出一页且保留两个图层，但 PDF 中的专色/ICC 不保证传递给 SVG；PDF 是印刷颜色依据。

## Blender 必须跟最终刀板同步

从同一清单建面片、铰链、窗口孔，使用纯画面 PDF 渲染的贴图。为了视频采样贴图不改变交付 PDF 的矢量属性。平面坐标、UV 和画面方向逐面核验，不能在 Blender 中手工拼一只近似盒子充当最终刀板的成品。

先做无贴图的线框折叠，观察底、侧面、提手、耳片、盖板的转向和顺序，再上贴图。真实开窗要贯穿网格，白色贴图不能冒充开孔。纸板背面默认无图；需要双面印刷时单独提供内面 UV/材质，基础示例的同贴图背面不适合作此证明。

普通铰链用层级变换即可；特殊盒型可能需要分段、约束、纸厚、柔性折弯或专门的模型代码。提手耳片应先就位，盖板最后到位并穿过槽位；具体先后由实际结构决定。用参考照片和局部剖视检查，不能为了画面看起来关上而让面板穿过纸片。

基础渲染器是零厚度刚性面片的运动演示，不检测碰撞或锁扣公差。复杂结构仍可复用几何、分层与验收方法，扩展模型后保留同一母版与版本依据。

视频包含展开状态、折叠过程、闭合成品和完整 360° 环绕，必要时加锁扣细节。相机根据运动范围取景，逐帧检查不裁边，观看全片确认无突然跳转、穿插、漏面或错误贴图。不能只看正面一个静帧就宣布视频通过。

最终保存打包贴图的 `.blend`；重开并测试资源独立性。PDF 改动后根据依赖关系重建贴图、模型或视频，不能混用旧版。验证细则见 [验收](acceptance.md)，断点和文件组织见 [恢复](recovery.md)。
