# 反复返工的经验

来源是同一纸盒任务的六段相关对话、工作文件及最终修订：从工具能力讨论、接手任务、继续设计，到图层、窗口和整面重绘。此处只总结可复用的行为，不公开原话、客户画稿、尺寸、聊天标识或账号信息。

下列“发生过的问题”是复盘观察；“应对方式”是本项目的建议。某次任务要求的语言、风格数量、窗口比例或云端账号，不应被提升成通用规则。

| 发生过的问题 | 为什么会反复 | 应对方式与完成证据 |
| --- | --- | --- |
| 给出概念图或工具介绍，完整刀板迟迟不出现 | 把视觉方向确认误认为最终交付 | 开始就列交付文件；每面最终落入完整 1:1 净片，视频可播放 |
| 不先看原 PDF 就排版；长宽比和页面比例漂移 | 用截图或生成图推断真实尺寸 | 数值读取与渲染双查；每次最终文件重测已知边长 |
| 独立面稿被当成一片连体盒 | 缺乏面之间的拓扑检查 | 验证纸张连通、共边、糊口与底部；共用折边不能同时切断 |
| 只有正面认真设计，顶底与背面敷衍 | 设计按图片数量计完成 | 面板清单逐项验收；整体展开图和完整环绕都覆盖全部面 |
| 屋顶变淡了，其他面还保留旧色 | 局部修改没有相邻面影响分析 | 每次颜色变化回看全盒与接缝；共享母版管理系列 |
| 英文/文案修改被旧要求覆盖 | 长对话没有明确当前决策 | 最新确认优先；冻结项、撤回项和当前文案记录在短清单 |
| “第三份”“左右空边”理解错 | 页、款、视觉边框、纸张余量混称 | 稳定 ID 配标注图；明确到底改画面还是物理开孔 |
| 窗口一会儿太宽一会儿太窄，比例反复估算 | 用口头百分比代替认可的参考边界 | 测量匹配已确认参考；物理最细纸桥另验，不能套统一比例 |
| 用户要整面重绘，却只微调刀线或盖旧边框 | 将设计问题转成容易执行的几何补丁 | 明确修改层级；重画角色、边框、装饰的整体构图 |
| 提高分辨率或嵌入 SVG 被当成矢量 | 把文件容器和实际内容混淆 | 实际路径导出；递归图像检查；编辑器里能选择独立对象 |
| 前期混画刀线，最后图层拆不干净 | 按颜色猜工艺内容，遗漏孔线和底线 | 从一开始分画面与工艺；最终一次隐藏整个工艺层并对比源文件 |
| PDF 更新了，Blender 仍展示旧窗口/画面 | 两条制作路线各自存版本 | 单一几何清单与最终画面；摘要依赖使旧模型/视频显式失效 |
| 盖板穿到内部、耳片没有穿槽，画面像闭合 | 用“看起来关了”代替机构推理 | 分析局部坐标、参考照片和闭合次序；盖与耳片按真实结构配合 |
| 把 UV 白缝或透明问题当几何缺口 | 没有先判断故障属于哪一层 | 用无贴图网格、UV 检查图和最终材质分别定位，再修改 |
| 环绕裁边、只验证正面静帧 | 取景按单一姿态设置 | 每帧自动取景检查 + 人工观看完整环绕和细节 |
| 云端导出卡住后不断点击或长时间无有效更新 | 没有识别真实提交控件或当前状态 | 看表单/按钮状态和下载结果；限定重试；保存断点后换可行路线 |
| 小样做通就停止，或反复要求已给出的许可 | 没有持续追踪完整任务范围 | 验证能力后完成整批；复用仍有效的授权，只问新增关键歧义 |
| 文件堆积、同名版本和长日志使接手困难 | 缺少一个当前事实来源 | 原输入、工作区、交付区分开；短状态表 + 稳定最终文件名 |
| 为展示成果准备公开全部工作目录 | 把案例资料与可复用项目混在一起 | 新建干净仓库，只放通用源码/指南；原创示例独立发布 |

这些经验不意味着每次都必须走同一个服务、同一套图像提示或同一种折叠算法。应固定的是尺寸、来源、授权、内容真实和验收证据；可变化的是创作方法、工具选择和探索顺序。
