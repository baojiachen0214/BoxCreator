# 验收：完成了什么，证据在哪里

自动通过、人工看过、尚未验证分别记录。没做实物打样，不写“可直接量产”；没有按目标印刷规范预检，不写“PDF/X 已通过”。成品视频证明可视化结果，不自动证明承重、扣合公差或碰撞都正确。

## 最终文件

| 文件 | 验收要点 |
| --- | --- |
| `master.pdf` | 多款时每款完整净片占一页；实际 1:1；两层可开关；无位图 |
| `artwork.pdf` / `dieline.pdf` | 与母版同页序、同尺寸、同 PageBox；画面不含生产线 |
| `variant-id.svg` | 每款完整可编辑净片；画面与所有工艺线各一个图层；无 `<image>` |
| `net.json` 或等效工程定义 | 面、孔、铰链、方向、尺寸和母版一一对应；摘要可追溯 |
| `folding.blend` | 使用最终几何及画面；贴图打包；路径可迁移；重开可渲染 |
| `folding.mp4` | 可完整解码；展开、折叠、闭合、完整环绕；对象不裁边 |
| `acceptance.json` / 简明说明 | 文件摘要、版本、检查证据、限制、尚待印厂或实物确认项 |

用户明确只需某一部分时按约定缩减。不要用几十页方案说明替代几页真正可制作的完整刀板。多款交付要保证总册和逐款文件相互对应，不能把“第几页”和“第几款”混用。

## PDF 与矢量

1. 读取最终文件而非生成前参数。记录 Media/Crop/Trim/BleedBox、UserUnit、旋转和已知边长。打印选择实际大小，不选适合页面。用源路径叠图检查原点与方向。
2. `boxcreator inspect` 检查图像 XObject、内联图像、嵌套 Form/Pattern/软遮罩与使用中的字体。再在矢量编辑器检查能否选择独立路径；SVG 检查 `<image>`、链接、文字字形和剪裁。只有扩展名为 SVG 不够。
3. `boxcreator check` 用渲染器分别开关图层，逐页与纯画面/纯刀线源文件比对。验收时还需实际打开图层面板，确认一次隐藏整个工艺层，不遗留窗口线、底部线或少数重复线。部分 PDF 浏览器忽略 OCG，使用支持图层的阅读器复核；正式送印保留纯画面文件。
4. 刀、折、孔路径不重复、不自交、不把共用折线当切线切断；各净片只有一个纸张实体。需要的糊口、底、顶、提手、耳片和插槽均有明确结构。细纸桥和孔到折痕的最短距离单独量测。
5. 使用目标印刷条件检查 ICC、专色名称、叠印、总墨量、黑版、透明度、字体嵌入/转曲、出血和安全区。`has_output_intent=true` 只证明存在输出意图字典，颜色操作计数也不覆盖 ICCBased/DeviceN/图案等所有色彩空间。专业印前检查单独记录软件、配置和结果。
6. 放大检查矢量描摹是否毁坏细节/文字，再按实际印刷尺寸看是否过密、边缘是否脏。逐面检查文案、角色、接缝、翻折后的方向和配色连续性。

`check` 的像素比较默认 96 DPI，适合发现图层串扰、偏移和丢内容；不代替高精度路径叠图、曲线误差测量与印刷尺寸细节检查。对于需要严格节点/颜色保真的任务，还需专用矢量/印前工具。

## 几何与 Blender

- 用 `validate` 验证清单；同时对照原刀板每个开孔与关键尺寸。清单内部自洽并不能证明来源正确。
- 检查三角网格覆盖纸张、避开孔洞；通过窗口实际能看到背后场景。故障先分辨是裁切、UV、材质、法线还是网格问题，不能一遇到白缝就加纸或挪刀线。
- 保存 PDF 几何摘要与画面文件摘要，再记录 Blender 的几何摘要和实际打包图像摘要。任何一个变化均使旧视频失效；仅重新命名文件不算更新。
- 关键帧观察折叠轴、父子局部坐标、相邻面关系；窗口、耳片、盖板和插舌方向正确。对锁扣应补局部视图或剖视，并明确纸厚、间隙与动作顺序的依据。
- 自动相机检查覆盖整段所有帧，人工观看全片与完整 360° 环绕；检查正反左右和顶底。不可用一张漂亮正面图证明背面/扣合正确。
- 把工程复制到新位置，断开原贴图路径，重新打开并渲染一帧；确认使用打包图像、无丢失链接。检查工程与视频的帧数、分辨率和摘要一致。
- 完整解码 MP4，确认帧数、时长、开头结尾内容和编码兼容性。预览视频需标为预览质量。

默认脚本验证取景和折叠参数，不计算碰撞、不自动检查所有最终面法线，也不验证锁扣或纸张强度。这些项目必须如实列为人工检查或实物待验，不能填自动通过。

## 报告写法

参考 [报告模板](../examples/acceptance.template.json)。`pass` 要附证据，`pending` 要说明需要谁做什么。示例没有锁扣、糊口、生产 ICC 或外轮廓出血，因此只能作为技术演示通过，不可宣称生产就绪。

最终对用户说明已完成的文件、关键变更和未验证项。不要展示内部重试记录、长日志和大量同名版本来代替结果。
